# Meenakshi Amman Hindi Classes

Android app for Meenakshi Amman Hindi Classes: the teacher runs courses and batches,
uploads PDF notes, adds YouTube (Unlisted) videos and schedules Google Meet / Zoom
live classes. Students sign up, request a batch, and see the material only after the
teacher approves them.

**Download the app:** [Meenakshi-Amman-Hindi-Classes.apk](https://github.com/SEENAV01/Meenakshi-Aman-/releases/download/latest/Meenakshi-Amman-Hindi-Classes.apk)
(always the newest build, from the Release named `latest`).
